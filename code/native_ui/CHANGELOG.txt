ASEapp Surface Builder CHANGELOG
================================

Unreleased
----------
- Integrate SIESTA final-structure to VASP conversion for embedded STRUCT_OUT, XV, and final outcoor data, including Bohr conversion, virtual/pseudo species, Geometry.Constraints to standard Selective dynamics, external cell selection when needed, and automatic opening of the saved VASP file.
- Refactor SIESTA final conversion into dedicated converter, VASP writer, and dialog classes. Replace the previous sequence of file dialogs with one drag-and-drop-capable review screen, background analysis, automatic cell discovery, inline validation, atom/element/constraint/cell preview, coordinate selection, and convert-and-open action.
- Fix macOS QOpenGLWidget context setup so the canvas no longer shows mirrored stale UI content on startup.
- Make Esc reliably clear atom selection by removing duplicate shortcut registration and letting the structure canvas handle Esc directly.
- Keep atom spheres strictly scene-scaled by removing the screen-space radius floor/density zoom scaling that made atoms inflate when zooming out, and remove fixed supercell multiplier/matrix/volume caps.
- Add configurable UMA relaxation from the Structure menu and surface panel. A run-settings window now lets users adjust the UMA model checkpoint path, Python command, task, device, fmax threshold, max steps, and selective-dynamics handling immediately before execution, then saves those values to the app settings JSON.
- Add a Python UMA worker script that runs ASE/fairchem in a separate process and reloads the optimized extXYZ result into the canvas.
- Automatically select the `uma_proj` (or another fairchem-enabled conda) Python for UMA, instead of accidentally using an unrelated PATH Python without fairchem-core.
- Show a live UMA log window with checkpoint/loading, energy, force, and FIRE step output, and preserve each run under the app-local `uma_logs` folder.
- Add sequential UMA batch relaxation for multiple selected structure files with shared settings, per-file results, cancellation, and a combined log.
- Save UMA results beside each source as `<original name>_UMA.vasp`; single-file and batch runs use the same naming rule.
- Add a dedicated DFT input batch command that applies one configured SIESTA/QE parameter set to all selected structures.
- Load every local structure file from a multi-file drag-and-drop operation, opening the structures in separate tabs.
- Rebuild Windows packages against official The Qt Company signed Qt 6.8.3 runtime DLLs, avoiding Smart App Control / Code Integrity failures from unsigned conda Qt, OpenSSL, and zstd DLLs.
- Added an integrated, multi-file SIESTA result analyzer with convergence plots, force/DM/stress threshold ratios, complete SCF energy columns, raw/constrained/residual forces, stress tensors, cell histories, output-tail monitoring, drag-and-drop folder loading, change-aware automatic refresh, file removal, and summary/detail CSV, JSON, and graph PNG export.
- Added an original-viewer-style convergence overview that displays energy, force/MD.MaxForceTol, and final SCF dDmax/DM.Tolerance together, plus geometry-step selection for inspecting the complete SCF energy and residual path with explicit PASS/incomplete diagnostics.
- Arrange the three convergence overview graphs horizontally, force the summary table text to readable black, and add color-coded run/energy/force/SCF/stress dashboard cards showing configured thresholds, latest values, ratios, and convergence state at a glance.
- Improve Geometry/SCF history readability with white and subtly alternating row backgrounds, dark text, and clearer grid/header colors. Force the SCF Geometry-step selector to use a compact, scrollable 10-row Qt popup because the native Windows popup otherwise ignores the visible-item limit and expands to nearly the full screen.
- Add interactive zooming to every SIESTA overview, detail, and SCF graph: mouse-wheel zoom anchored at the cursor, left-drag panning, and Reset-button/double-click restoration of the full data range. Preserve the current view while live data refreshes.
- Cap mouse-wheel zoom-out and panning at each graph's initial full-data range; scrolling back now returns to the automatic maximum view instead of expanding beyond it.
- Use the SIESTA `SystemLabel`/`Label` as the default final-structure VASP filename (for example, `ideal_9layer.vasp`), with safe filename sanitization and source-name fallback when no label is present.

Version 1.3.3 - Vacuum placement and large-scene UX fixes
---------------------------------------------------------
- Add vacuum layers incrementally so adding top/bottom vacuum no longer removes the previously added opposite side.
- Mark out-of-cell placement previews in red and ask before auto-expanding the vacuum region to place them.
- Keep the current supercell transform label through vacuum, atom placement, precursor placement, and termination edits.
- Make Ctrl+drag range selection follow the visible rectangle exactly instead of selecting atoms just outside it.
- Add Alt+left-drag panning, reduce duplicate projection work, cull off-screen primitives, keep two-color bond gradients, switch large/dragging atom fills to a flat fast-render path, and limit expensive periodic-image bond generation for very large structures.
- Add a screen-space atom selection index, bucketed fast depth ordering for large interactive scenes, persisted startup display defaults, and collapsible right-side tool sections.
- Embed the default app settings JSON in the executable resources, save user app settings to a dedicated app config JSON instead of structure files, and add a Settings menu/dialog plus menu-bar access to the main side-panel operations.

Version 1.3.2 - Bond display cutoff and macOS startup fix
---------------------------------------------------------
- Changed the primary bond display UI to edit only the maximum displayed bond distance for each species pair, such as Ga-N, Ga-H, and N-H.
- Kept element-pair rows ordered by the element order in the loaded structure instead of alphabetic order.
- Added a GUI self-test that verifies Ga/N/H structures collapse to Ga-N, Ga-H, and N-H summaries and that lowering a display cutoff hides bonds without moving atoms.
- Added a macOS startup splash screen that appears before the main window is ready.
- Added Windows self-signed certificate trust helper files for local development-signed packages.

Version 1.3.1 - Windows Smart App Control packaging fix
----------------------------------------------------------
- Rebuilt the Windows launcher/ZIP without re-signing third-party Qt/OpenSSL runtime DLLs, preserving their original file hashes for Smart App Control reputation checks.
- Added a payload manifest so cached standalone startup files are validated before reuse and stale/corrupt caches are re-extracted.
- Kept first-party ASEapp executables signed with the local development certificate when available.

Version 1.3.0 - Matrix supercell transforms
------------------------------------------------
- Added optional direct 3x3 integer lattice-transform input to the Supercell dialog, so rotated supercells such as sqrt(2) x sqrt(2) R45 can be generated without adding one-off presets.
- Kept the existing a/b/c multiplier workflow as the default, while showing determinant and expected atom count validation in matrix mode before Apply.
- Preserved matrix-based supercell state through snapshots, undo/redo, and tab switching.
- Added a GUI self-test assertion for the sqrt(2) x sqrt(2) R45 transform, including determinant atom count, rotated cell lengths, orthogonality, and fractional-coordinate bounds.
- Updated the operation guide and packaged quick-start text for the new matrix-input workflow.

Version 1.2.0 - VESTA-like display and startup polish
------------------------------------------------------
- Added a side preview to the Atom legend PNG export dialog, plus label prefix/suffix fields and manual element-order controls.
- Cached the extracted standalone payload under the user's local app-data folder using an embedded-payload hash, so repeat launches skip the slow ZIP extraction path.
- Replaced string-formatted spatial grid keys in atom-neighbor searches with compact integer keys to reduce allocation overhead for larger structures.
- Added an immediate standalone-launcher splash screen that stays visible during embedded ZIP extraction and fades out when the native UI starts.
- Increased the VESTA-like bond stroke width while keeping one-piece, constant-width two-color bond rendering.
- Ignored sub-0.50 A symmetry near-overlap artifacts for display density and bond rendering so the magnemite CIF keeps normal atom sizes.
- Adjusted the default ball-and-stick atom scale and fit radius to match VESTA more closely; the initial fit now prioritizes visible atoms instead of forcing the full cell box on screen.
- Changed normal bonds to VESTA-style half-and-half coloring using the colors of the atoms at each end.
- Added the Outside cell toggle to show/hide VESTA-like periodic image atoms and bonds crossing the unit-cell boundary.
- Added a GUI self-test assertion that the Outside cell toggle adds periodic boundary bonds.
- Fixed the missing Save As path for CIF export; current structures can now be written as P1 CIF files.
- Regenerated the verified Windows standalone launcher and macOS DMG as v1.2.0.
